\# README&#x20;

This project focuses on the full lifecycle of financial data processing for Chinese A-share markets, covering data download, validation, feature engineering, and fundamental factor analysis.   The codebase is structured into modular directories: \`src\_data\_download\` handles fetching raw data (e.g., daily price/volume, money flow, intraday minutes, and fundamental data) with utilities for deduplication, verification, and merging new datasets. \`src\_data-diagnose\` implements data diagnosis workflows, including integrity checks and report generation to ensure data quality. \`src\_data\_domain\_feature\` builds domain-specific features across price-volume, moneyflow, chip, fundamental, and intraday summary domains, with tools for cleaning and aligning data to trade calendars.   \`src\_fundmental\_factors\` develops factor libraries (daily/quarterly) using Polars for efficient data processing, alongside preprocessing, transformation, and backtesting modules to validate factor performance. Supplementary architecture documents outline data check requirements, refactoring plans, and Alpha model engineering specs, while data documentation details the scope of macro, index, and stock datasets processed.  All modules prioritize data integrity and reproducibility, with test scripts to validate data loading, casting, and merging processes.
